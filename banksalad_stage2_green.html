02 · USER CASES

유저 케이스 6유형

CASE A 🚪

이해가 안 돼서
상담 중 이탈하는 고객

보험 용어와 구조가 복잡해 설명 도중 포기하고 상담을 중단한다.

CASE B 🤷

이해는 부족하지만
상담사 말대로 결정하는 고객

내용을 잘 모르지만 일단 믿고 따라가는 방식으로 의사결정을 위임한다.

CASE C 🏦

비교안은 봤지만
브랜드 때문에 보류하는 고객

조건을 비교했음에도 낯선 보험사에 대한 막연한 불안으로 최종 결정을 미룬다.

CASE D 📋

이해는 됐지만 안이 하나뿐이라
따라갈 수밖에 없는 고객

내용은 이해했지만 선택지가 없어 추천안을 수동적으로 수용한다.

CASE E 🔍

이해는 했지만 내 보험
문제를 체감 못 하는 고객

설명은 들었으나 현재 보험의 문제가 본인 상황과 연결되지 않아 필요성을 못 느낀다.

CASE F 🌊

비교 정보가 너무 많아
결정을 미루는 고객

과도한 비교 정보로 인해 판단이 마비되어 결정 자체를 다음으로 미룬다.

유저 케이스별 VP · TE · WOW 포인트
03 · SOLUTION STRUCTURE

케이스별 솔루션 구조

CASE A

이해가 안 돼서 상담 중 이탈하는 고객

VP — 가치 제안
복잡한 보험 내용을 짧고 쉬운 설명으로 이해하고, 상담을 끝까지 이어갈 수 있다
TE — 신뢰 증거
  • 현재 보험 문제를 3줄 요약으로 진단
  • 어려운 용어를 쉬운 언어로 번역
  • 핵심 문제만 먼저 보여주는 요약 화면
WOW — 감동 포인트
"아, 내 보험 문제를 처음으로 이해했다"는 순간
상담이 어렵지 않고 따라갈 만하다고 느끼는 순간
CASE B

이해는 부족하지만 상담사 말대로 결정하는 고객

VP — 가치 제안
추천을 듣되, 왜 이 선택이 맞는지 이해한 뒤 스스로 결정할 수 있다
TE — 신뢰 증거
  • 추천안과 대안을 나란히 비교
  • 추천 이유를 항목별로 설명
  • 고객이 직접 선택 기준을 확인하는 비교 구조
WOW — 감동 포인트
"이번엔 따라가는 게 아니라 내가 이해하고 고른다"는 순간
추천의 근거가 내 기준으로 납득되는 순간
CASE C

비교안은 봤지만 브랜드 때문에 보류하는 고객

VP — 가치 제안
브랜드가 아니라 보장과 비용 기준으로 합리적인 선택을 할 수 있다
TE — 신뢰 증거
  • 대형사·중소형사를 동일 기준으로 비교
  • 브랜드 프리미엄과 총보험료 차이 시각화
  • 재무건전성(K-ICS) 등급 병기
WOW — 감동 포인트
"이름보다 조건으로 봐도 이 안이 더 낫네"라고 느끼는 순간
막연한 브랜드 불안보다 비교 근거가 더 크게 작동하는 순간
CASE D

이해는 됐지만 리모델링안이 하나뿐이라 따라갈 수밖에 없는 고객

VP — 가치 제안
하나의 정답이 아닌, 여러 대안 중 내 기준에 맞는 선택을 할 수 있다
TE — 신뢰 증거
  • 최소 2개 이상 대안 설계 제시
  • 각 안의 장단점과 적합 조건 명시
  • 가격형·균형형·보장형으로 선택 구조화
WOW — 감동 포인트
"선택지가 있으니 진짜 내가 결정하는 느낌이다"라는 순간
추천이 아닌 비교 후 내가 선택한다고 느끼는 순간
CASE E

이해는 했지만, 내 보험의 문제 자체를 체감하지 못하는 고객

VP — 가치 제안
내 보험의 어떤 부분이 실제 문제인지 구체적으로 인식할 수 있다
TE — 신뢰 증거
  • 현재 보험의 부족·중복·과다 지출 진단
  • 또래 대비 보험료·보장 비교
  • 리모델링 전후 차이 직관적 시각화
WOW — 감동 포인트
"지금 보험이 그냥 괜찮은 게 아니었구나"를 깨닫는 순간
상담이 선택이 아니라 필요라고 느끼는 순간
CASE F

비교 정보가 너무 많아 오히려 결정을 미루는 고객

VP — 가치 제안
복잡한 비교 정보를 핵심만 요약해, 빠르고 확신 있게 결정할 수 있다
TE — 신뢰 증거
  • 비교 요소를 3개 핵심 기준으로 압축
  • 한 화면 요약 카드 제공
  • 추천 우선순위와 선택 가이드 함께 제시
WOW — 감동 포인트
"볼 건 많았는데, 이 세 가지만 보면 되는구나"라는 순간
정보 과부하가 정리되며 결정이 쉬워지는 순간
